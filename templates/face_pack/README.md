# 头像包模板

做一套自己的对话头像, 放进游戏的 `mod/` 文件夹, 在设定里切换。头像包可以装任意多个, 互不影响; 想让别人一起做, 把这个文件夹复制出去改名就是一个新包。

这个文件夹里有:

| 文件 | 作用 |
|---|---|
| `README.md` | 就是你正在看的说明 |
| `info.json` | 设定里显示的名字, 改 `name` 就行 (可以不要, 不要就显示包名) |
| `frames.json` | 帧清单: 一共哪些头像、每张要多大 (50 个头像目录, 175 帧) |

校验和打包的脚本在仓库的 `tools/mod/face_pack.py`。

## 一分钟上手

1. **复制模板**到任意位置, 目录名就是包名 (只用小写字母、数字、下划线, 例如 `face_mine`)。
2. **放头像**: 在里面建 `Face/<头像目录>/tN.webp`, 例如 `Face/FACE01/t0.webp`、`Face/Face05/t3.webp`。目录名和帧名照 `frames.json` 写。
3. **校验**: `python3 tools/mod/face_pack.py check face_mine`, 有错会告诉你哪张图哪里不对。
4. **打包**: `python3 tools/mod/face_pack.py pack face_mine`, 生成 `face_mine.pck` (需要 Godot 4.7.2, 见 [编译指南](../../docs/编译指南.md))。
5. **安装**: 把 `face_mine.pck` 放进游戏的 `mod/` 文件夹 (和 `resource/` 并排), 启动游戏, 设定 (F1) 里「头像风格」选你的包。

## 头像怎么做才对

| 项目 | 要求 |
|---|---|
| 格式 | `.webp` (带透明通道)。游戏只读 `tN.webp`, 放 png / jpg 会被忽略, 校验时会报错 |
| 尺寸 | **每一帧都必须与经典头像一样大**, 清单里写了, 例如 `FACE01/t0` 是 600×480。尺寸不对, 头像在对话框里的大小和位置就会变, 所以校验不通过 |
| 名字 | `Face/<头像目录>/tN.webp`, **目录名和帧名区分大小写**, 照 `frames.json` 写 (有 `FACE01` 也有 `Face05`, 还有原版笔误 `FASE07`, 都要原样) |
| 数量 | 不用做全: 缺哪一张, 游戏里那张自动用经典头像。可以先只做主角, 以后再补 |
| 画质 | 只在高清画质下生效 (默认就是); 原版画质下一律用经典头像 |

**怎么知道每个目录、每一帧是谁、什么表情?** 经典头像就在你自己生成的资源里: 跑过 `生成资源包.bat` / 资源生成工具 后在 `hd4x/Face/<头像目录>/tN.webp`; 只有资源包的话, 用 `tools/release/unpack_pck.gd` 把 `hd_images.pck` 解出来看 (解包命令见 [tools/README.md](../../tools/README.md) 的「把 `.pck` 解回目录」, 包的说明见 [资源包](../../docs/打包/资源包.md))。`tN` 的 N 是表情序号, 对话里用哪张由剧情决定, 你只需要保证同一目录同一序号对应同一个人的同一种表情。

## 包名与设定里的显示

- 包名 = 目录名, 也是包里 `res://mod/<包名>/` 的名字; 设定里每个头像包是一项, 选项文字取 `info.json` 的 `name`, 没写就显示包名。
- 包名不能是 `classic`、`auto`、`hk` (这些是设定里的特殊值); 不要叫 `face_hk` (那是官方港漫头像包的名字, 同名只能装一个)。可以用 `--id` 临时改: `pack face_mine --id face_mine2`。
- 装了好几个包时, 设定里「头像风格」左右键轮流切换; 缺省 (`auto`) 用排第一的包, 官方港漫包 `face_hk` 优先, 其余按包名排。
- 命令行临时指定: `--face-style=face_mine` (或 `--face-style=classic` 用经典头像)。

## 常见问题

- **设定里没有「头像风格」这一行**: 一个头像包都没识别到。`.pck` 要放在游戏目录的 `mod/` 里 (不是 `resource/`); 包里要有 `Face/` 目录 (用本工具打的包一定有)。手机上放哪里见 [手机安装与资源包](../../docs/手机安装与资源包.md)。
- **选了包, 头像没变**: 画质是不是原版画质? 那一帧你做了吗 (校验会打印「覆盖 N / 175 帧」)? 切换头像风格后下一次显示头像才换。
- **校验说尺寸不对**: 用图片软件把那张图缩放/裁成清单里写的像素数, 比例不同的话要补边或裁切, 不要拉伸变形。
- **想把一个现成的头像目录整个替换**: 把该目录下 `t0`、`t1`… 全部做出来即可, 不用动别的目录。

## 分享与版权

- 模板和脚本跟随仓库的开源许可 (GPL-3.0-only), 你做的**头像图片版权归你自己**。
- 头像是对原作美术的再创作: 请不要把原版图片、也不要把本项目生成的 AI 放大图直接打进包里分发; 分发自己的包前, 请自己确认素材的授权。本仓库不收录、不托管任何头像素材。
- 想和别人一起做: 约定好包名和各人负责的头像目录, 各自做好 `Face/<目录>/` 再合并到同一个包目录, 最后统一跑一次 `check` 和 `pack`。
